# CNS Assignment 2 — Caesar Cipher with Cryptanalysis

## Files
- `caesar_cipher.py`: runnable Python 3 implementation.
- `CNS_Assignment2_Caesar_Report.docx`: report aligned with the assignment rubric.
- `sample_output.txt`: output captured by executing the implementation.
- `README.md`: run instructions.

## Requirements
Python 3.9 or later. No third-party packages are required.

## Run
```bash
python caesar_cipher.py
```

## Features
- Caesar encryption and decryption.
- Preserves uppercase/lowercase and punctuation, spaces, and digits.
- Brute-force attack that lists all 26 possible keys.
- Built-in demonstration and round-trip test.

## Important security limitation
Caesar cipher has only 26 possible shifts and is not suitable for protecting real data.
Use this project for coursework and learning only.
